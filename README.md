# TheOutsideWorld
My first game! Take your character on a journey to play in some lush grass. Avoid any screen-agers who will lull you into doom scrolling! I built this project with Coding with Russ's tutorial on YouTube. I tried to make a game where the theme is going outside and avoiding devices, and I was mostly successful!
